Stage 1: Build the core in Ada

Create aircraft records containing a callsign, altitude, speed and position. Write functions that classify and filter aircraft.

Stage 2: Connect real data

Retrieve aircraft states from OpenSky and parse the JSON. Handle missing values and failed API requests.

Stage 3: Add monitoring rules

Detect when an aircraft enters a geographic area or changes altitude significantly. Write tests for each rule.

Stage 4: Make it visible

Display aircraft on a map or build a simple dashboard that communicates with your Ada program.
